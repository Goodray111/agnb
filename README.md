# 一诺 · 粉丝专题站（示例版 v0）

成都AG超玩会一诺（徐必成）粉丝向专题站。纯静态网页，无需服务器，直接用浏览器打开即可。

## 目录结构

```
my-website/
├─ index.html          单页入口（7 个板块 + 导航 + 页脚）
├─ css/
│  └─ style.css        全部样式（主题变量 / 组件 / 响应式）
├─ js/
│  └─ main.js          交互（深色切换 / 移动菜单 / 灯箱 / 留言本地存储）
└─ README.md
```

## 本地预览

直接双击 `index.html`，或在 VS Code 里用 Live Server 打开。

## 设计说明

- 主色：AG 红 `#d81e2c` + 深灰 `#0f1013` + 白，金色 `#e9b949` 点缀
- 顶部固定导航；首页全屏 Banner；卡片式布局；竖向时间线；图片画廊灯箱
- 深色 / 浅色双模式（右上角按钮切换，记忆在 localStorage）
- 移动端自适应（≤760px 折叠菜单、图集两列）
- 留白充足、无明显弹窗
